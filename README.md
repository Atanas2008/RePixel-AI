# RePixel-AI

Програмата използва готови модели Real-ESRGAN; не обучава нов модел. В този
програма подобрява снимки и видео през командния ред или локален интерфейс в
браузъра. По избор може да възстановява лица с GFPGAN.

## 1. Инсталирайте Python

Инсталирайте **Python 3.11** от [python.org](https://www.python.org/downloads/).
В Windows отметнете „Add Python to PATH“. Отворете Terminal (macOS/Linux) или
PowerShell (Windows) в папката на проекта. Проверете версията:

```text
python --version
```

На macOS/Linux може да е нужно да използвате `python3.11` вместо `python`.

## 2. Създайте виртуална среда

Windows:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Ако PowerShell забрани активирането, изпълнете
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` и повторете
командата за активиране.

macOS/Linux:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

Когато средата е активна, командата `python` по-долу сочи към нея. Python
3.10 не се поддържа от избраната поправена версия на Pillow.

## 3. Инсталирайте библиотеките

Първо подгответе инструментите и NumPy:

```bash
python -m pip install --upgrade pip
python -m pip install setuptools==80.9.0 wheel==0.46.3 Cython==3.3.1 numpy==1.26.4
```

След това инсталирайте PyTorch според компютъра:

* **NVIDIA, Windows/Linux:** инсталирайте актуален NVIDIA драйвер и изпълнете:

  ```bash
  python -m pip install torch==2.10.0 torchvision==0.25.0 --index-url https://download.pytorch.org/whl/cu128
  ```

  При проблем с драйвера проверете вариантите на
  [pytorch.org](https://pytorch.org/get-started/locally/).
* **Без NVIDIA, Windows/Linux:** за работа с процесора изпълнете:

  ```bash
  python -m pip install torch==2.10.0 torchvision==0.25.0 --index-url https://download.pytorch.org/whl/cpu
  ```

* **macOS:** изпълнете:

  ```bash
  python -m pip install torch==2.10.0 torchvision==0.25.0
  ```

  На Apple Silicon програмата използва MPS, когато е наличен.

Накрая инсталирайте останалите библиотеки:

```bash
python -m pip install --no-build-isolation -r requirements.txt
```

Първоначалната инсталация може да отнеме време и място на диска. BasicSR
изисква предварително инсталираните по-горе инструменти; опцията
`--no-build-isolation` ги използва вместо да изтегля второ копие на PyTorch.

## 4. Пробвайте снимка

Поставете например `photo.jpg` в папката на проекта и изпълнете:

```bash
python enhance.py photo.jpg --scale 2
```

При първо стартиране моделът се изтегля от официалния проект в `models/`;
необходим е интернет. Резултатът е `output/photo_enhanced.jpg`. Оригиналът
остава непроменен; ако резултатът вече съществува, се добавя номер.
Папките `models` и `output` се създават автоматично.

Още примери:

```bash
python enhance.py photo.png --scale 4 --model realesr-general-x4v3
python enhance.py photo.jpg --scale 2 --faces
python enhance.py photos --scale 2 --model realesr-animevideov3 --tile 128
```

Последният пример обработва всички поддържани снимки и видео файлове непосредствено в
папката `photos`. Моделите са `RealESRGAN_x4plus` (подробни снимки),
`realesr-general-x4v3` (по-бърз) и `realesr-animevideov3` (аниме/рисунки).
Резултатите могат да се различават според снимката; възстановяването не
гарантира оригиналните детайли. Максималният размер е 3840 × 2160 пиксела,
като пропорциите се запазват; големите снимки се намаляват при нужда.
Програмата показва избраното устройство: CUDA, MPS или CPU.

## 5. Инсталирайте FFmpeg за видео

Ако сте инсталирали предишна версия, активирайте `.venv` и повторете
последната команда от стъпка 3, за да добавите новите библиотеки.

* **Windows:** в PowerShell изпълнете `winget install Gyan.FFmpeg`, след което
  затворете и отворете терминала отново.
* **macOS:** инсталирайте [Homebrew](https://brew.sh/), после изпълнете
  `brew install ffmpeg`.
* **Ubuntu/Debian:** изпълнете `sudo apt update` и `sudo apt install ffmpeg`.
  При други Linux дистрибуции използвайте съответния пакетен мениджър.

Проверете, че и двете команди работят:

```bash
ffmpeg -version
ffprobe -version
```

Ако не работят, уверете се, че FFmpeg е инсталиран и папката му е в PATH.
Видео обработката използва PyAV (библиотеки на FFmpeg) за последователна
обработка на кадрите и FFmpeg за добавяне на звука, без временни снимки.

## 6. Пробвайте видео

Поставете кратко `video.mp4` в папката на проекта и изпълнете:

```bash
python enhance.py video.mp4 --scale 2 --model realesr-general-x4v3 --tile 128
python enhance.py video.mp4 --scale 2 --model realesr-general-x4v3 --faces
```

Отворете `output/video_enhanced.mp4` и проверете картината и звука в началото
и в края. Поддържат се MP4, MOV, MKV и AVI; резултатът е H.264 MP4 с CRF 18.
Оригиналът не се променя. Имената на съществуващите резултати се запазват.
За цяла папка посочете нейното име вместо името на файла.

Програмата първо преброява кадрите, после измерва времето за първия кадър и
показва приблизително общо време. По време на обработката показва номер,
процент и приблизително оставащо време. Кадрите запазват времевите си
отметки, включително при променлива кадрова честота. Звукът се копира, когато
кодекът е подходящ за MP4; иначе се преобразува в AAC. Пропорциите се
запазват приблизително, като размерите се закръглят до четни за H.264.
Временното видео се изтрива при завършване, грешка или Ctrl+C. При внезапно
спиране на компютъра може да остане скрита папка `.repixel-*` в `output`,
която може да изтриете ръчно.

## 7. Възстановяване на лица

Добавете `--faces` към командата за снимка или видео, или отметнете
„Възстановяване на лица с GFPGAN“ в интерфейса. Опцията е изключена по
подразбиране. Първия път се изтеглят GFPGAN и моделите за откриване и
обработка на лица в `models/`; необходими са интернет и свободно място.
GFPGAN е проект под лиценз Apache-2.0; CodeFormer не се използва. Проверете
условията на използваните модели и зависимости при търговска употреба.

AI може да измисли детайли и да промени приликата; резултатът не е доказателство
за истинския вид на лицето. Във видео лицата се обработват кадър по кадър и
може да трептят. Опцията изисква допълнителна памет и време.

## 8. Локален графичен интерфейс

След инсталацията от стъпки 1–3:

* **Windows:** щракнете два пъти върху `start.bat`.
* **macOS/Linux:** разрешете стартирането веднъж с `chmod +x start.sh`, след
  което стартирайте `start.sh` от файловия мениджър или с `./start.sh` от
  терминала. В macOS може да е нужно да изберете отваряне с Terminal.
* Ако двойното щракване не работи, активирайте `.venv` и изпълнете
  `python app.py` в папката на проекта.

Браузърът се отваря автоматично. Ако това не стане, отворете адреса, показан
в терминала (обикновено `http://127.0.0.1:7860`). Интерфейсът работи само на
този компютър; не затваряйте терминала, докато го използвате.
За да не могат други потребители на компютъра да получат достъп до файловете
ви през интерфейса, въведете потребител `repixel` и кода, изписан в терминала.
Кодът се сменя при всяко стартиране. Екранът за вход на Gradio показва
английските надписи „Username“ (потребител), „Password“ (код) и „Login“ (вход).

1. Натиснете „Изберете снимки или видео“ и изберете един или повече файлове.
   За пакетна обработка можете вместо това да въведете пътя към папка.
2. Изберете 2× или 4×, модел и при желание възстановяване на лица.
3. Натиснете „Старт“. Следете лентата за напредък; при видео се показва кадърът.
4. Отворете или изтеглете готовите файлове. Първата снимка се показва до
   оригинала за сравнение. Всички резултати остават и в папката `output`.
5. За да спрете програмата, затворете терминала или натиснете Ctrl+C в него.

При избор през браузъра Gradio създава временни копия в лична системна временна
папка, която се изтрива при нормално излизане или Ctrl+C. При внезапно
спиране на компютъра може да остане папка `repixel-gradio-*` в системната
временна папка; можете да я изтриете ръчно. Файловете не се качват в облак;
изтеглят се само нужните отворени AI модели.

## 9. Проблеми

* **AMD/Intel видеокарта:** тази версия използва CPU, ако CUDA или MPS не са
  налични. За Vulkan ускорение разгледайте отделния проект
  [realesrgan-ncnn-vulkan](https://github.com/xinntao/Real-ESRGAN#portable-executable-files-ncnn);
  той не е интегриран тук.
* **Недостатъчна памет:** опитайте `--tile 128` или `--tile 64`. Обработката
  е на блокове, но самите входно и изходно изображение също заемат RAM.
* **`functional_tensor`:** BasicSR използва премахнат модул на torchvision.
  `core/models.py` локално го насочва към съвместимата функция на torchvision;
  не е нужно да редактирате инсталираните библиотеки.
* **Грешка при изтегляне:** проверете интернет връзката и повторете командата.
  Незавършеното изтегляне се изтрива автоматично.
* **`No module named ...`:** активирайте `.venv` и повторете стъпка 3.
* **Липсва FFmpeg/ffprobe:** изпълнете стъпка 5, после отворете нов терминал.
* **Не може да се прочете кадър или липсват времеви отметки:** файлът може да е
  повреден. Опитайте първо да го преобразувате в нов MP4 с FFmpeg.

Тестовете се пускат с `python -m unittest discover -s tests -v`. Те използват
заместващ модел и не изтеглят AI тегла.
